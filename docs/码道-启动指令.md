## 一、规格里有一个错的样例值，必须改

`spec.md` 的 5.2.1.3.a 和 6.2.5 两处都写着：

> 卫星号 1、星座 1、标志 0xF、移位 12/8 → **0x1F01**

这个值是错的，正确值是 **0x110F**：

```
(1 << 12) | (1 << 8) | 0xF
= 0x1000  | 0x100   | 0xF
= 0x110F
= 4367
```

对照二进制能看出 0x1F01 是位段错位，不是四舍五入之类的偏差：

```
0x110F = 0b100_0100_001111   ← 星座位 0x100、标志位 0xF 各就各位
0x1F01 = 0b111_1100_000001   ← 星座与标志全跑偏
```

差值 3570（0x1F01 − 0x110F），量级上根本对不上，属于笔误而非设计差异。

**这个错误源自任务单里我方写的举例，不是你算错。** 但请把 `spec.md` 这两处改成 0x110F，
B2 的单元测试期望值一律以 0x110F 为准。写断言前自己再算一遍，别照抄文档。
