# 二期任务单：卫星数量可配 + 参数自然化 + 动态波动

> 建立于 2026-11-23。背景：一期完成后真机实测发现模块伪造 **8 颗**，
> 而使用者所在环境的真实读数是 **60–80 颗**（校园跑 App 显示 67，高峰 80+）。
> 伪造值比真实值少了一个数量级，本身就是异常特征。
> 二期目标：**让伪造的卫星表在外观统计上贴近真实环境。**

---

## 一、技术约束（先读，这几条决定了实现方式）

### 1. GPS 单星座最多 32 颗，80 颗必须跨星座

`svidWithFlags = (svid << shift) | (constellation << 8) | flags`，
每个星座的 svid 从 1 开始各自编号。单靠 GPS 凑不出 60 颗。

各星座可用范围（实现时以 AOSP `GnssStatus` 常量为准，动手前先核对）：

| 星座 | 常量 |
|---|---|
| GPS | 1 |
| SBAS | 2 |
| GLONASS | 3 |
| QZSS | 4 |
| BEIDOU | 5 |
| GALILEO | 6 |
| IRNSS | 7 |

### 2. 「参与定位」的卫星必须是子集

当前 `FLAGS_FULL` 给全部卫星打了 `USED_IN_FIX` 标记。真实系统只把信号最好的十几到二十几颗
用于定位。80 颗全标"参与定位"是明显的伪造特征。

**要求**：在视野内 = N 颗；`USED_IN_FIX` 只给其中 CN0 最高的一部分（默认 22 颗）。

### 3. 载频按星座分开

现在全部填 `1575.42`（GPS L1）。跨星座后必须区分：

| 星座 | 载频 (MHz) |
|---|---|
| GPS / QZSS / GALILEO | 1575.42 |
| GLONASS | 1602.00 |
| BEIDOU | 1561.098 |
| IRNSS | 1176.45 |

### 4. system_server 内不许起线程、不许用定时器

所有波动必须由**当前时间戳推导**，无状态。同一次读取内结果一致，跨时间窗口自然变化。

## 二、核心算法

### 2.1 数量：平滑波动，精确可控

```
N(t) = svmin + (svmax - svmin) × (0.5 + 0.5 × sin(2π × t / T_count))
```

- `t` = 当前毫秒时间戳，`T_count` = 数量波动周期（默认 180 秒）
- 结果四舍五入取整，始终落在 `[svmin, svmax]`
- 默认 `svmin=58, svmax=82`（对齐使用者环境的 60–80，留一点余量）

### 2.2 卫星进出：按可见度排序取前 N 颗

候选池固定（大小 = `svmax + 20`，按星座配额分配）。每颗卫星有一个独立的可见度函数：

```
score_i(t) = 0.5 + 0.5 × sin(2π × t / T_i + phase_i)
```

- `T_i` 在 240–900 秒之间，按 svid 派生的伪随机值（同一颗卫星周期恒定，像真实轨道）
- `phase_i` 同理由 svid 派生，保证每颗卫星错开
- 取 `score` 最高的 `N(t)` 颗作为当前可见

**效果**：卫星缓慢进出，边界上的卫星随数量波动自然消失/出现，而不是整批跳变。

### 2.3 仰角：球面均匀分布

```
elev = acos(1 - u × (1 - cos(maxElevRad)))   // u 为 0..1 随机
```

- 简单说：天顶方向的卫星少，低仰角的多，这是球面几何的必然结果
- 限制在 5°–85°，避免出现 0°（地平线）这种不可见位置
- 每颗卫星的仰角随时间为**缓慢漂移**（±0.5°/分钟），不要一个值定死

### 2.4 CN0：与仰角正相关（这是最能骗过检测的一条）

```
cn0 = 25 + 18 × sin(elev) + noise
```

- `noise` 在 ±3 之间，同样由时间与 svid 派生
- 结果裁剪到 15–48 dB-Hz
- 低仰角卫星信号弱、高仰角强，符合物理规律
- 实测参考：真实 GPS 卫星 35–45，GLONASS 略低 30–42，Beidou 中高轨 35–48

### 2.5 方位角：0–360 均匀，随时间缓慢漂移

不要用 `i × 22.5` 这种等距分布——等距是明显的人工痕迹。
每颗卫星的方位角按 `(baseAzimuth_i + t / T_azimuth) % 360` 缓慢旋转，`T_azimuth` 约 600 秒/圈。

## 三、配置通道：系统属性，adb 可调，不重启

| 属性 | 含义 | 默认值 |
|---|---|---|
| `debug.gnssspoof.enable` | 总开关，`0` 时完全透传真实数据 | `1` |
| `debug.gnssspoof.svcount` | 固定数量（设置后忽略波动） | 未设 |
| `debug.gnssspoof.svmin` | 波动下限 | `58` |
| `debug.gnssspoof.svmax` | 波动上限 | `82` |
| `debug.gnssspoof.fixcount` | 参与定位的卫星数 | `22` |

- **`enable=0` 这个开关是本期重点**：有了它才能在不卸载、不重启的情况下采到
  "同一台机器、同一环境"的真实基线，与伪造值做对照。做对照时这是唯一可靠手段。
- 属性读取要有缓存（默认 3 秒过期），不要每次钩子调用都读 5 个属性。
- 属性不设时全部用默认值；`svcount` 设了就固定数量、不做波动。
