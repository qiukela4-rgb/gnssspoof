## 四、B3 开工注意

### 1. 签名校验的范围，按上一轮裁决执行

- 配置文件存在且四字段完整 → 启用 release 签名
- 存在但字段缺失/为空 → **仅当本次任务包含 release 时**抛 `GradleException`；纯 debug 构建打 warning 后跳过
- 不存在 → 跳过，release 出 unsigned

判断本次是否涉及 release 用 `gradle.startParameter.taskNames` 即可，别引入新依赖。
**不要**在配置阶段无条件抛异常——上一轮已经说明理由。
